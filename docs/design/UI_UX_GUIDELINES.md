## 1. 핵심 UI/UX 설계 원칙

1. **무스크롤 원칙 (Zero-Scroll Paradigm):**
   - 어떠한 해상도(PC 16:9, Steam Deck 16:10, 모바일 9:16)에서도 메인 게임 테이블의 핵심 정보(손패, 6대 바, 판돈, 플레이어 순위)는 스크롤 없이 단일 화면에 100% 들어와야 합니다.
2. **모바일 가독성 보장 정책 (`MIN_SCREEN_PX = 11.0`):**
   - `ui/tokens.gd`의 `fs(design_px)` 함수를 통해 윈도우 스케일 축소 시에도 실물 픽셀 11px 이하로 텍스트가 줄어들지 않도록 수학적으로 하한선을 방어합니다.
3. **듀얼 반응형 레이아웃 (Dual Responsive Layout):**
   - **가로 모드 (1280×720 / 1280×800):** 6개 바가 가로 1열로 펼쳐지고, 좌측에 순위 HUD, 하단에 손패 5장이 배치되는 카지노 테이블 뷰.
   - **세로 모드 (720×1280 / 430×932):** 6개 바가 2열 3행으로 정렬되고, 상단에 압축 요약 HUD, 하단에 엄지 접근 영역 손패가 배치되는 모바일 전용 뷰.

## 2. 카드 배치 및 오버랩 규칙 (Card Overlap Rules)

한 술집에 3~8인의 카드가 동시에 놓일 수 있으므로 공간 효율과 가독성을 모두 만족하는 계층적 렌더링을 적용합니다.

### 2.1 인원수별 카드 렌더링 모드
- **1 ~ 3장:** 기본 카드 뷰 (이름, 주사위 기호, 일러스트 전체 표시).
- **4 ~ 8장 (압축 모드):**
  - **분리 기준:** 경찰(`RAZZIA`)과 도박꾼(`ZOCKER`)이 모두 존재할 때만 경찰 상단 1줄 / 도박꾼 하단 1줄의 2단 그리드로 분리. 한 종류뿐일 때는 1줄(또는 필요시 2줄)로 가로 공간을 최대한 넓게 활용.
  - **식별자:** 텍스트 이니셜 대신 **작은 플레이어 원형 초상화(Portrait)**를 카드 좌측 상단에 렌더링하여 다국어 및 동명이인 혼란을 원천 방지.
  - **절대 보호 영역:** **주사위 눈(Die Pip)과 플레이어 초상화가 위치한 모서리는 겹침에 의해 절대 가려지지 않도록** 겹침 오프셋 방향을 계산.
  - **미니 카드 주사위 최소 크기:** 1280×800 기준 최소 가로·세로 16×16px 유지.
- **호버 및 포커스 확대 (Hover Zoom):**
  - 마우스 오버 또는 게임패드 포커스 시 해당 카드가 Z-인덱스 최상단으로 1.25배 확대되며, 플레이어 전체 이름과 상태 툴팁이 팝업.

## 3. 조작계 및 입력 모드 자동 전환 (`platform/input_mode_manager.gd`)

게임은 사용자의 마지막 입력을 0.05초 내로 감지하여 UI 프롬프트를 실시간 갱신합니다.

| 모드 | 감지 트리거 | UI 동작 변화 |
|---|---|---|
| `TOUCH` | 화면 직접 터치/스와이프 | 포커스 링 숨김, 터치 타깃 최소 44×44pt 확보, 탭 확인 모달 지원 |
| `MOUSE` | 마우스 커서 이동 및 클릭 | 호버 하이라이트 활성화, 우클릭 정보 보기 지원 |
| `GAMEPAD` | 조이패드 아날로그 스틱/D-pad/버튼 입력 | 아르데코 황금 포커스 링(Gold Focus Ring) 표시, LB/RB 바 순회, A/B 확인/취소 |
| `KEYBOARD` | 방향키 및 엔터/스페이스/ESC 입력 | 게임패드와 동일한 포커스 네비게이션 트리 지원 |

## 4. 모달 및 팝업 규격

1. **협상 패널 (`ui/nego_panel.gd`):**
   - 판돈 분배 슬라이더: $5,000 단위 스냅.
   - 프리셋 버튼: [25%] [50%] [75%] 원터치 분배 지원.
   - 고정 노이즈 적용: 슬라이더를 반복 조작해도 AI의 거절 경계선을 역산할 수 없음.
2. **컴팩트 결투 뷰 (`ui/compact_duel_view.gd`):**
   - 테이블 중앙 오버레이. 리볼버(도전자) vs 금고(방어자) 아이콘 명시.
   - 주사위 굴림 애니메이션(0.6초) 및 즉시 스킵 지원.
3. **일시정지/메뉴 버튼:**
   - 톱니바퀴 대신 표준 햄버거 메뉴(≡) SVG 아이콘 사용 (`assets/icons/system/`).
   - 시스템 메뉴 팝업 시 배경 게임 루프 완전 일시정지(`get_tree().paused = true`).
