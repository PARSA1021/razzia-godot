# 다국어 (한국어 / English)

Phase 28에서 넣은 번역 체계입니다. 외부 라이브러리 없이 Godot의 `TranslationServer`만 씁니다.

## 구조

| 파일 | 역할 |
|---|---|
| `ui/i18n.gd` | 언어 적용(`apply`), 번역(`t`), 시스템 기본 언어 |
| `i18n/en.gd` | 영어 표 (자동 생성, 직접 고치지 않음) |
| `tools/i18n/en_*.py` | 영어 번역 원본 (화면별 파일). `en_zz_polish.py`는 마지막에 읽혀 앞의 초안을 덮어씀(원어민 수준 교정) |
| `tools/i18n/build_en.py` | 코드의 한국어 문자열을 모두 찾아 표와 맞춰 보고 `i18n/en.gd`를 만듦 |

- **키는 코드에 적힌 한국어 문장 그대로입니다.** 한국어로 실행할 때는 아무것도 찾지 않습니다.
- 영어 표에 없는 키는 한국어 원문이 그대로 나옵니다. 빈칸이 되거나 오류가 나지 않습니다.
- `project.godot`의 `internationalization/locale/fallback="ko"`가 없으면, 한국어 모드에서도 영어가 나옵니다(Godot 기본 대체 언어가 en이기 때문). 지우지 마세요.

## 화면에 붙이는 법

| 경우 | 방법 |
|---|---|
| Label·Button에 고정 문장 | 그대로 둡니다. Godot가 표시할 때 번역하고(자동 번역), 언어를 바꾸면 바로 다시 그립니다. 버튼의 `text`에는 키(한국어)가 남으므로 테스트는 한국어로 버튼을 찾을 수 있습니다. |
| 숫자 등을 끼워 넣는 문장 | `tr("슬롯 %d") % n` (노드 안), `T.t("...")` (static 함수). **번역한 다음에** 값을 넣습니다. |
| `_draw()`에서 그리는 글자 | `T.t()`로 번역해서 그립니다. 언어가 바뀌면 `queue_redraw()`. |
| 번역하면 안 되는 글자 | `auto_translate_mode = Node.AUTO_TRANSLATE_MODE_DISABLED` (언어 이름 "한국어 / English", "언어 · Language") |

- 값의 순서가 언어마다 다르면 `%`를 쓰지 말고 `"{0}".format([...])`를 쓰세요. Godot의 `%`는 `%2$s` 같은 순서 지정을 지원하지 않습니다.
- `tools/i18n/build_en.py`는 키와 번역의 `%s %d {bar}` 자리 표시가 같은지 검사합니다.

## 번역하지 않는 것 (의도)

- **플레이어 이름:** 사람이 입력한 이름과 AI 캐릭터 이름(Vito, Lola …). 기본 이름 "나"만 영어에서 "You"로 보입니다.
- **술집 이름과 카드 글자:** COLIBRI · COTTON CLUB …, ZOCKER / RAZZIA. 카드에 인쇄된 이름이라 두 언어에서 같습니다.
- **느와르 스타일의 영어 표제:** RAZZIA 로고, ROUND, FINAL ROUND, DEALER, DECK, NEXT ROUND, PICK A CARD, PLAY CARD, SKIP, ROLL THE DIE, ACCEPT/DUEL 같은 짧은 영어 단어. 한국어 모드에서도 원래 이렇게 썼습니다.
- **금액 표기:** `$35,000`.
- **진단 로그:** `platform/steam_deck_manager.gd`의 판단 근거(사용자 화면에 나오지 않음).

## 언어 선택과 저장

- 메뉴 오른쪽 위의 `한국어 | English`, 게임 중 멈춤 패널의 `언어 · Language`.
- 선택은 `settings.cfg`의 `[general] language`에 저장됩니다. 저장 슬롯과는 따로 관리됩니다.
- **기본값:**
  - 이 기능 전부터 쓰던 사람(설정 파일이 이미 있음)은 한국어입니다.
  - 처음 설치한 사람은 시스템 언어가 한국어면 한국어, 아니면 영어입니다.
  - 테스트 실행은 항상 한국어입니다.
- 게임 중에 언어를 바꿔도 게임 상태는 바뀌지 않습니다(`tests/i18n_slots_test.gd` F). 멈춤 패널이 새 언어로 다시 열리고, 판 위의 글자는 다시 그려집니다.
- 진행 문구(화면 가운데 한 줄)도 바로 바뀝니다. 값을 끼워 만든 문구는 `_now_live(func(): return tr(...) % [...])`로 "만드는 방법"을 기억해 두었다가, 언어가 바뀌면 다시 만듭니다.

## 영어 문장 원칙 (Phase 29 교정)

- `(s)` 복수형을 쓰지 않습니다. 숫자가 붙는 문장은 `Gamblers out: 3`처럼 "이름: 숫자" 꼴로 씁니다.
- 버튼과 탭은 짧은 단어(Resume, Leave, Gameplay, Sound, Controls)로 씁니다.
- 캐릭터 대사는 느와르 말투의 짧은 문장으로 씁니다. 장면 대사는 한국어에서 가장 넓은 줄보다 넓지 않아야 합니다(`ui_scene_story_test`).
- 같은 한국어 키가 두 곳에서 다른 뜻으로 쓰이면 키를 나눕니다. 예: 기록의 "게임"(Games)과 설정 탭의 "게임 진행"(Gameplay).

## 새 문장을 넣을 때

1. 코드에 한국어로 씁니다. 숫자를 끼워 넣는다면 `tr()`이나 `T.t()`로 감쌉니다.
2. `python3 tools/i18n/build_en.py`를 실행합니다. `MISSING`으로 나온 문장을 `tools/i18n/en_*.py`에 영어로 추가합니다.
3. 다시 실행하면 `i18n/en.gd`가 만들어집니다(문제 0개면 종료 코드 0).
4. 영어 화면을 검사합니다: `... qa_gamepad_playthrough_test.gd -- lang=en`, `qa_tutorial_test.gd -- lang=en`. 화면에 한글이 하나라도 남으면 실패합니다.
