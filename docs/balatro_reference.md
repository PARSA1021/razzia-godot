# Balatro 레퍼런스 분류표 (Razzia UI)

Balatro의 로고·일러스트·아이콘·개별 카드 디자인·화면 구성은 사용하지 않습니다. 원리(가독성, 손맛, 피드백)만 참고합니다.
정체성은 1920년대 느와르/스피크이지: 짙은 녹색 펠트, 어두운 목재, 아이보리 종이, 황동, 사용자 제공 카드 아트.

| 요소 | 분류 | Razzia 적용 | 상태 |
|---|---|---|---|
| 손패 부채꼴 배치 | 적극적으로 참고 | 5° 팬, 바깥 카드 살짝 하강 | 완료 |
| hover/선택 시 카드 상승 | 적극적으로 참고 | 상승 + 똑바로 펴짐 + 깊은 그림자(`CardView.lift`) | 완료 |
| 카드 설명 툴팁 | Razzia에 맞게 변형 | 카드 위 팝업 대신 안내 줄에 규칙 한 줄 힌트(hover/포커스/선택) | 완료 |
| 좌측 정보 레일 | Razzia에 맞게 변형 | 라운드, 머니덱, 테이블 총액, 상대 칩 | 완료 |
| 손패 옆 큰 실행 버튼 | 적극적으로 참고 | PLAY CARD 를 손패 오른쪽에 배치 | 완료 |
| 펠트 테이블 배경 | Razzia에 맞게 변형 | 독자 셰이더(섬유 노이즈, 램프 비네트, 느린 연기 흐름) | 완료 |
| 상황별 배경 색조 | Razzia에 맞게 변형 | RAZZIA 청색, 협상/결투 호박색, 종료 금색, 모션 줄이기 시 정지 | 완료 |
| 카드 분배/제출/뒤집기/점수 팝 | 적극적으로 참고 | 딜인, 비행, 플립, 금액 팝, 스킵 | 완료(이전 단계) |
| 덱 더미 시각화 | Razzia에 맞게 변형 | 현재는 "MONEY DECK n장" 텍스트. 더미 그래픽은 후속 과제 | 미적용 |
| 터치/게임패드 포커스 | 적극적으로 참고 | 크림색 이중 링, 선택(금색)과 구분 | 완료 |
| 화면 흔들림/CRT/과한 파티클 | 적용하지 않음 | 가독성과 접근성 우선 | - |
| 점수 배수(칩×배) 구조 | 적용하지 않음 | Razzia 규칙과 무관 | - |
| 조커/상점/덱 빌딩 UI | 적용하지 않음 | 해당 시스템 없음 | - |
| 로고, 일러스트, 아이콘, 카드 디자인 | 적용하지 않음 | 저작권, 고유 아트 사용 | - |
