## 3. 우선순위 정의 (Priority Definitions)

- **P0 (출시 불가 - Showstopper):** 해결되지 않으면 Steam 출시 자체가 불가능하거나 법적/기술적 치명타를 입는 문제 (상표권 분쟁, 빌드 불가, 세이브 파손, 심사 반려).
- **P1 (출시 전 필수 - Critical):** 상용 게임으로서의 기본 구색을 갖추기 위해 출시 전에 반드시 완료되어야 하는 작업 (Steamworks 업적, 클라우드 세이브, 테스트 패스, 상점 에셋).
- **P2 (품질 고도화 - Important):** 게임의 깊이와 만족도를 크게 높이는 작업 (가상 키보드, 유물 연출 강화, 추가 음향).
- **P3 (출시 후 업데이트 - Post-launch):** 출시 이후 v1.5/v2.0 업데이트로 진행할 선택적 개선 (신규 유물 12종, 알 카포네 챌린지 모드, P2P 온라인 멀티).
